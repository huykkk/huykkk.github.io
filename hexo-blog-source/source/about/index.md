# 关于我

这里是 Huyk Blog - PM小白的快落小屋。

## 关于博主

你好，我是胡寅恺，一个在医疗信息化领域深耕多年的产品经理。日常与 HIS、PACS、LIS 等核心系统打交道，参与智慧医院和互联网医院的产品设计与落地。我相信好的产品不是冷冰冰的功能堆砌，而是对复杂场景的优雅简化。

这个博客记录了我对产品、技术、医疗行业的思考与实践。从 B 端产品设计方法论的提炼，到医疗信息化产品的深度复盘，再到日常阅读和生活中的感悟——所有文字都力求真实、有料、可操作。

## 写作初衷

产品经理的日常往往被需求文档、原型图、项目排期填满，很容易陷入"做了很多、想了很少"的困境。写博客是我对抗这种惯性的一种方式——强迫自己把碎片化的经验整理成体系化的认知，把隐性的判断变成显性的方法论。

如果你也是产品经理，或者对医疗信息化感兴趣，希望这里的文字能给你一些启发。
